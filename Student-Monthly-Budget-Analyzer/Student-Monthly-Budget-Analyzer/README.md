# Student Monthly Budget Analyzer 💰

## 📌 About the Project

**Student Monthly Budget Analyzer** is a beginner-friendly Python command-line application designed to help students understand and analyze their monthly income and expenses.

The program collects monthly income and different expense categories from the user, calculates total expenses, remaining balance, category-wise expense percentages, and savings rate, and displays a clear monthly budget report.

This project is developed as part of **Python Fundamentals – Module 1 Mini Project**.

## 🎯 Objectives

- Understand Python fundamentals through practical implementation.
- Take user input using `input()`.
- Understand variables and data types.
- Perform calculations using arithmetic operators.
- Practice type conversion using `float()`.
- Generate formatted and readable output.

## ✨ Features

- Enter student's name and monthly income.
- Record expenses in different categories:
  - Food
  - Travel
  - Study Materials
  - Mobile/Internet
  - Other Expenses
- Calculate total monthly expenses.
- Calculate remaining balance.
- Calculate category-wise expense percentages.
- Calculate overall savings rate.
- Display a formatted monthly budget report.

## 🛠️ Technologies Used

- **Concepts:** Variables, Data Types, Input/Output, Type Conversion, Arithmetic Operators, String Formatting
- **External Libraries:** None
